# SockLove Security

> Report privately. Never in public.

---

- **Write to [sockpusher@tuta.io](mailto:sockpusher@tuta.io)** about any
🧦💜 **[SockLove](https://github.com/socklove-eth)** repository or
📄 **[Page](https://github.com/socklove-eth/pages/tree/v1.0)**.
- **Send** the release or **CID**, the steps, and what an attacker gains; a
rough report beats none. You are credited in the next release's *What changed*,
or left unnamed if you ask. No answer? Write again.
- **The current release only.** Pinned bytes are never patched. A re-pin, when
[STANDARD.md](https://github.com/socklove-eth/pages/blob/v1.0/STANDARD.md)
allows one, is a new release: the
💍 **[Ring](https://etherscan.io/address/socklove.eth)**, at its **Threshold**,
points the name at it. The old CID stays vulnerable: trust the name.

[SECURITY.md](https://github.com/socklove-eth/pages/blob/v1.0/SECURITY.md).
