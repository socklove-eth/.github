# SockLove Contributing

> Open to read, copy and fork. Closed to commit.

---

**No outside commits** in any
🧦💜 **[SockLove](https://github.com/socklove-eth)** repository. From the
🧎 **[Proposal](https://github.com/socklove-eth/.github/blob/v1.0/RELEASE.md)**
on, nothing enters that both owners of the
💍 **[Ring](https://etherscan.io/address/socklove.eth)** have not signed; only
they commit. Instead:

- **Open an issue**, for an error: name the file or the **CID**, quote the line
or the text.
- **Make a fork**, under your own name, as the repository's licence allows;
name, logo, favicon and
🖼️ **[Plate](https://github.com/socklove-eth/.github/blob/v1.0/profile/assets/plate.jpg)**
are reserved:
[TRADEMARKS.md](https://github.com/socklove-eth/.github/blob/v1.0/TRADEMARKS.md).

A vulnerability is reported privately, never in public:
[SECURITY.md](https://github.com/socklove-eth/.github/blob/v1.0/SECURITY.md).
